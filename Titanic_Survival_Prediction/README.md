# Titanic Survival Prediction

## Objective
Predict whether a passenger survived the Titanic disaster using a Decision Tree Classifier.

## Dataset
Titanic Dataset (Kaggle)

## Concepts Covered
- Data Cleaning
- Preprocessing
- Feature Selection
- Train-Test Split
- Decision Tree
- Prediction
- Accuracy
- Overfitting
- Pruning

## Results

Original Decision Tree Accuracy:
78.77%

Pruned Decision Tree Accuracy:
79.89%
